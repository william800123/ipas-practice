# iPAS AI 練習室

支援手機的個人刷題網站，包含初級／中級選擇、考前衝刺、診斷、考古題模擬、弱項加強、錯題重考與 PDF 題庫匯入。

- 2026-11-06 題庫：760題（700題官方公告＋60題原創診斷）。
- 初級：兩科，114第四梯次與115第一、二、三次；每科原卷50題／75分鐘。
- 中級：三科，114第二梯次與115第一次；每科原卷50題／90分鐘。正式報考科一加科二或科三擇一。
- 目前官方題庫皆為單選；網站也支援真正複選，採全對且無多選才得分。
- PDF在瀏覽器內轉檔：先預覽、核對題型／答案，再匯入個人題庫。掃描PDF需先OCR，沒有答案的題目需人工補填。
- 免登入。成績及題庫存在目前瀏覽器，不會自動跨裝置同步；匯出備份包含個人題庫，可在另一裝置匯入。

詳見 [PDF匯入與題型檢查說明](PDF匯入與題型檢查說明.md)。歷年考試設定及題目以提供教材為依據，不代表最新官方公告。原創診斷與公告試題明確分開，未附官方逐題解析的題目搭配主題複習。

GitHub Pages使用main分支根目錄，無後端安裝需求。PDF轉檔使用隨站台提供的Mozilla PDF.js 6.5.438，授權見 vendor/PDFJS-LICENSE.txt 及相關字型授權檔。
