# iPAS AI 練習室

支援手機的個人刷題網站：初級／中級分級入口、考前衝刺、基礎診斷、官方考古題、錯題重考及弱項加強。

- 初級：兩科，30 題原創診斷＋200 題公告試題；完整模擬每科 50 題／75 分鐘。
- 中級：三科，30 題原創診斷＋150 題公告試題；完整模擬每科 50 題／90 分鐘。科一必考，科二或科三擇一報考。
- 初級提供 114／115 年混合練習；中級提供 114 年原卷及同卷隨機排序。
- 圖表、公式、程式碼及題組共用資料保留，可點圖放大。
- 免登入，暱稱、成績及未完成試卷僅保存在目前瀏覽器。換裝置或清除瀏覽器資料前，請先匯出 JSON 備份，再於其他裝置匯入。
- 沒有雲端帳號、共享成績或自動跨裝置同步。

題目與考試設定依提供的歷年公告試題、學習指引、簡章及勘誤整理。原創診斷明確標示；公告未附逐題解析時，以官方答案搭配主題重點複習。歷年規範及工具情境按原公告版本，不代表最新公告。

GitHub Pages 使用 main 分支根目錄，無需安裝或執行後端。
